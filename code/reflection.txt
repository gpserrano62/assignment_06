In completing this project I built a program that read coffee shop reviews and later showed what each person likes and disliked. The biggest thing I learned from this assignment was caching, specifically in the sentiment_step, entities_step, and subjects_step functions. By caching this data you only need to use the API key once to read the file and it saves the responses it finds in a different section. One of the hardest parts of this assignment was when I early on used ruff --fix. This deleted a function I hadnt worked on yet to make all the tests pass.
